# XPress Ocean Website

Portfolio website for XPress Ocean (Custom Brokers, Freight Forwarders, Logistics - Surat).
Owner & Customs House Agent: Rekha Yadav.

## Structure
- index.html     - page content
- css/style.css  - all styling (colours are CSS variables at the top of the file)
- js/main.js     - animations, mobile menu, enquiry form (WhatsApp / email)
- images/        - logo and photos from the company PDF

## Run
Open index.html in a browser. To publish, upload the whole folder to any static host
(Netlify, GitHub Pages, Vercel, or normal web hosting). Fonts load from Google Fonts (needs internet).
